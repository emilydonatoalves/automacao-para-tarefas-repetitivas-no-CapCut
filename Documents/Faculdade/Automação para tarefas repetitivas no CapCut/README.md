# Automação de edição de vídeos no CapCut com Python

Projeto desenvolvido para automatizar tarefas repetitivas de edição de vídeos no CapCut utilizando Python e PyAutoGUI.

## Objetivo

Automatizar parte do processo de edição de vídeos, reduzindo tarefas manuais e repetitivas.

## Tecnologias utilizadas

- Python
- PyAutoGUI
- Pyperclip

## Automação realizada

O programa automatiza quando já temos um layout salvo em presets para corte de videos com comandos e elementos repetitivos, como:

- Ajuste da proporção do vídeo
- Inserção de presets (Camadas salvas como presets)
- Inserção de ajustes e efeitos
- Inserção de texto
- Inserção de música (salva como preset)
- Corte das camadas de acordo com o tamanho do vídeo
- Inserção de títulos com quebra de linha
- Suporte a caracteres com acentuação
- Exportação do vídeo

## O que aprendi

Este projeto foi desenvolvido para solucionar uma dor que editores de vídeos tem com tarefas repetitivas pré determinadas, com o objetivo de automação de tarefas utilizando Python e interação com interfaces gráficas.

Durante o desenvolvimento, trabalhei com:

- Automação de mouse e teclado
- Controle de tempo de execução
- Manipulação de strings
- Quebra de linha em textos
- Clipboard
- Organização de scripts
- Bibliotecas externas em Python
- Git e GitHub

## Observações

Este projeto utiliza coordenadas de tela através do PyAutoGUI. Por isso, as posições dos elementos podem precisar ser ajustadas de acordo com resolução, tamanho da janela e configuração do CapCut.

Os arquivos de vídeo utilizados durante os testes não fazem parte deste repositório.
